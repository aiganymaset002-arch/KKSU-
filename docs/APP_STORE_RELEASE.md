# KKSU Online — публикация в App Store и TestFlight

## Параметры сборки

| Параметр | Значение |
|---|---|
| Bundle ID | `kz.kksu.onlineapp` |
| Название на экране | KKSU Online |
| Version / Build | 1.0 / 2 (каждая новая загрузка — Build +1) |
| Минимальная iOS | 17.0 |
| Устройства | только iPhone |
| Категория | Education |
| Шифрование | только HTTPS → `ITSAppUsesNonExemptEncryption = NO` (вопрос об экспорте при загрузке не задаётся) |
| Иконка | `KKSU/Assets.xcassets/AppIcon.appiconset` (1024×1024) |
| Launch Screen | генерируется Xcode (`UILaunchScreen`) |
| Сервер | Supabase (Франкфурт), только publishable key в приложении |

Разрешения: приложение не использует камеру, микрофон, геолокацию и отслеживание (ATT).
- Фото выбираются через `PhotosPicker`, а он не требует доступа к галерее.
- Документы выбираются через системное окно файлов.
- Уведомления локальные: напоминания о дедлайнах и занятиях.

Поэтому в Info.plist нет ни одного `Usage Description`, и они не нужны.

## Встроенные покупки (In-App Purchase)

Цифровой контент в iOS продаётся **только** через App Store: курсы, программы, статус ученика, подписки, сертификация педагога, размещение курса. Оплата переводом (Kaspi и др.) остаётся только для очных услуг и мероприятий: конференции, конкурсы, 3D-печать, консультации (Guideline 3.1.3(d)/(e)).

Создайте в App Store Connect (**Monetization**) товары с **точно такими** идентификаторами. Они не обязаны совпадать с Bundle ID.

| Тип | Product ID | Цена |
|---|---|---|
| Consumable | `kz.kksu.online.unlock.usd10` … `usd300` (16 шт.: 10, 15, 20, 25, 30, 35, 40, 50, 60, 90, 100, 120, 150, 200, 250, 300) | цена = число в названии, USD |
| Auto-Renewable (одна группа «KKSU») | `kz.kksu.online.sub.monthly` | 15 USD / месяц |
| | `kz.kksu.online.sub.yearly` | 150 USD / год |
| | `kz.kksu.online.sub.family.monthly` | 25 USD / месяц |
| | `kz.kksu.online.sub.family.yearly` | 250 USD / год |

Для каждого товара нужны название, описание и скриншот для проверки (экран оплаты). Перед первой отправкой должен быть подписан **Paid Apps Agreement** (Business).

## Сервер (Supabase)

Ещё раз выполните `backend/supabase/schema.sql` в **SQL Editor**. Файл можно запускать повторно: он добавит хранилище файлов `kksu-files`, через которое ученики открывают файлы учителя на своих телефонах.

Остальные настройки — в `backend/README.md`: письмо с кодом восстановления пароля `{{ .Token }}` и SMTP.

## Загрузка в TestFlight (на Mac)

### Способ 1 — Xcode (рекомендуется)
1. Откройте `KKSU.xcodeproj`, затем target **KKSU** → **Signing & Capabilities**:
   - включите **Automatically manage signing**;
   - в **Team** выберите свою команду (не Personal Team).
2. Подключите iPhone хотя бы один раз, чтобы Xcode зарегистрировал устройство.
3. Вверху выберите **Any iOS Device (arm64)**, затем меню **Product → Archive**.
4. В **Organizer** нажмите **Distribute App → App Store Connect → Upload**.
5. Через 10–30 минут сборка появится в App Store Connect → **TestFlight**.

### Способ 2 — командная строка (тот же процесс без кнопок)
```sh
xcodebuild -project KKSU.xcodeproj -scheme KKSU -configuration Release \
  -destination 'generic/platform=iOS' -archivePath build/KKSU.xcarchive archive

xcodebuild -exportArchive -archivePath build/KKSU.xcarchive \
  -exportOptionsPlist ExportOptions.plist -exportPath build/export
```
Второй команде нужен вход в Apple ID в **Xcode → Settings → Accounts**.

Для полной автоматизации (CI, Fastlane) нужен **ключ App Store Connect API**: файл `AuthKey_XXXX.p8`, **Key ID** и **Issuer ID** (**Users and Access → Integrations**). Ключ хранится только на вашем компьютере или в секретах CI. Файлы `*.p8` уже добавлены в `.gitignore`. Пароль Apple ID для этого не нужен и в проект не записывается.

## Возрастной рейтинг

Отвечайте на анкету честно:
- в приложении есть **общение пользователей** (чат);
- есть **пользовательский контент**: проекты, файлы;
- он **модерируется**: жалобы, блокировка, фильтр слов.

Скорее всего получится **9+**. Если анкета даст 13+ из-за чата, это допустимо.

Категорию **Kids** не выбирайте. Для неё Apple требует родительский контроль перед каждой внешней ссылкой (YouTube, Zoom, сайты). Приложение для детей 7–18 лет и без Kids Category соблюдает правила 1.3 и 5.1.4: нет рекламы, нет сторонней аналитики, нет трекинга.
